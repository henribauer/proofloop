**Pitfalls**
1. **Trigger-only nodes:** Calendly, Cal.com, Typeform and Jotform cannot write back through official nodes (repo dirs above). An audit saying "n8n integrates with Calendly" overclaims.
2. **German finance stack:** No official node for Lexware Office, sevDesk or DATEV. Lexware allows 2 requests/s and returns 429 beyond that (https://developers.lexware.io/docs/). DATEV production access needs registration and per-client enablement (one blog only, unverified).
3. **Licence is a judgment call:** The licence allows use "only for your own internal business purposes" (https://raw.githubusercontent.com/n8n-io/n8n/master/LICENSE.md). The FAQ says consulting and building workflows is free, but making n8n available to customers so they connect accounts and build workflows is not (https://docs.n8n.io/n8n-community-license/sustainable-use-license). Proofloop recommends and does not host, so it is fine. A "we run it for you" offer needs a licence check with license@n8n.io.
4. **Community nodes:** Unverified ones are not available on Cloud (https://docs.n8n.io/integrations/community-nodes/installation-and-management/). Mark them "unverified third-party code" in any recommendation.
5. **Webhook exposure:** The default can be None. Tally's `Tally-Signature` must be checked by hand (inference: Crypto node), and the signature check is not offered by the Webhook node's documented auth methods.
6. **Google OAuth on self-hosted:** You must create your own client. A Testing-status external app means tokens expire after 7 days (https://docs.n8n.io/integrations/builtin/credentials/google/oauth-single-service/). Failures are silent without an error workflow.
7. **Audit trail is weak by default:** Execution data is pruned after 336 h or 10,000 executions (https://docs.n8n.io/hosting/configuration/environment-variables/executions/). Log streaming is Enterprise-only (https://docs.n8n.io/log-streaming/). Executions also hold enquirers' personal data, so GDPR retention applies. Not suited to strict audit duties without Enterprise or external logging.
8. **Version churn and JSON handling:** 3.0 removes npm installs, some legacy nodes, and "Import from URL" (https://docs.n8n.io/changelog/v30-breaking-changes.md). Exports carry credential names, which "could be sensitive" (https://docs.n8n.io/workflows/export-import/). Any workflow JSON Proofloop emits must be a stub with no credential IDs.

**Not verified:** Retry max-tries defaults; max Wait duration; Google Forms integration route; DATEV portal terms; existence of any lexoffice community node; Guardrails introduction version; whether S3 binary storage is Enterprise-only; template licence beyond the summariser-read terms.
